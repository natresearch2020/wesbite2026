# National Research Consultancy — GitHub Pages FIXED edition

This version intentionally uses a FLAT folder structure. There is no `assets` directory to accidentally omit.

## IMPORTANT: Replace files on your existing GitHub repository
1. Open https://github.com/natresearch2020/wesbite2026
2. Select **Add file → Upload files**.
3. Drag **ALL files from inside this extracted folder** into the upload area, not the ZIP itself and not the enclosing folder.
4. Scroll down and click **Commit changes**. If GitHub asks whether to replace existing files, confirm.
5. In the repository root, confirm that you see `index.html`, `about.html`, `services.html`, `contact.html`, `style.css`, `main.js`, `logo.webp`, `icon.png`, `favicon.ico`, and `NRC-Company-Flyer.pdf` together at the same level.
6. Open Settings → Pages: deploy from branch `main`, folder `/(root)`.
7. Wait for the deployment to finish and refresh https://natresearch2020.github.io/wesbite2026/ with Ctrl+Shift+R.
8. To verify assets, visit these URLs directly:
   - https://natresearch2020.github.io/wesbite2026/style.css
   - https://natresearch2020.github.io/wesbite2026/logo.webp
   - https://natresearch2020.github.io/wesbite2026/NRC-Company-Flyer.pdf

## Google enquiry form
The Contact page embeds your Google Form and also offers a direct open-in-new-tab link.
In Google Forms, confirm the form is published, accepting responses, and not restricted to your organization. In the Responses tab, link the form to Google Sheets.
Google controls whether its form can be displayed and submitted; the site cannot override Google sign-in or sharing restrictions.
